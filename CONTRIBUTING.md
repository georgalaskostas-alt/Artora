# Contributing to Artora

1. Read docs/MASTER_PLAN.md and docs/PROGRESS_LEDGER_GR.md before work.
2. Use feature branches and PRs; no unreviewed direct feature merges.
3. Add tests and update feature matrix/progress ledger for each implemented feature.
4. Never commit signing credentials, API keys, customer images or copyrighted lesson assets.
5. Keep Greek/English translations and accessibility aligned.
6. Record unverified assumptions explicitly.
