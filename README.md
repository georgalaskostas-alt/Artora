# Artora — Learn to Draw

Artora is an original iPhone/iPad drawing education application, designed to teach drawing on paper with step-by-step instruction and future on-device assessment.

## Current phase
**Phase 0 — Project foundation**. No AI assessment capability is implemented yet.

## Principles
- Original assets, lesson content and interface; no copying proprietary Simply Draw content.
- Native SwiftUI architecture (iOS/iPadOS).
- Local-first privacy, child-safe defaults, no camera upload by default.
- Greek and English localization.
- Build/test gates before accepting a feature as complete.
