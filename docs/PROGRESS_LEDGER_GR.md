# Artora — Ημερολόγιο προόδου

Τελευταία ενημέρωση: 25/11/2026

## Ολοκληρώθηκαν
- Δημιουργήθηκαν README, Master Plan, αρχιτεκτονική, πίνακας χαρακτηριστικών και σχέδιο δοκιμών στο main.
- Δημιουργήθηκε branch feature/ios-foundation.
- Προστέθηκε αρχική δομή SwiftUI: home, φίλτρα μαθημάτων, δίγλωσσες οδηγίες και αποθήκευση προόδου.
- Προστέθηκαν 4 πρωτότυπα δείγματα μαθημάτων, unit tests και GitHub Actions CI.
- Χρήση XcodeGen για αναπαραγώγιμο Xcode project.

## Έλεγχοι
- Δεν έχει ολοκληρωθεί πραγματικό Xcode build/test. Αναμένεται επιβεβαίωση CI.
- Το οπτικό υλικό μαθημάτων είναι προσωρινά SF Symbols, όχι ολοκληρωμένες εκπαιδευτικές εικονογραφήσεις.

## Επόμενα βήματα
1. CI και διόρθωση compilation/test προβλημάτων.
2. Πέντε διαφορετικές premium προτάσεις home screen και επιλογή.
3. Εικονογράφηση πραγματικών σταδιακών μαθημάτων.
4. Accessibility, localization string catalogs, UI tests.
5. Camera/AI αξιολόγηση μετά την επιβεβαίωση πυρήνα μαθημάτων.

## Κανόνας
Πριν από κάθε ανάπτυξη διαβάζουμε MASTER_PLAN, ARCHITECTURE, FEATURE_MATRIX, TEST_PLAN και PROGRESS_LEDGER_GR. Κάθε αλλαγή συνοδεύεται από ενημέρωση ημερολογίου, tests και αποτίμηση αποτυχιών.
