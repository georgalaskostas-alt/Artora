# Artora — Ημερολόγιο προόδου

Τελευταία ενημέρωση: 25/11/2026

## Ολοκληρώθηκαν
- Επιβεβαίωση συνδεδεμένου GitHub repository.
- Έναρξη τεκμηρίωσης προϊόντος και τεχνικής αρχιτεκτονικής.
- Καθορισμός αρχικού πλάνου υλοποίησης και ελέγχων.

## Σε εξέλιξη
- Δημιουργία αρχικής SwiftUI εφαρμογής.
- Πέντε πρωτότυπες προτάσεις GUI.

## Εκκρεμούν
- Επιβεβαίωση πραγματικού build σε Xcode.
- Σχεδίαση και δοκιμή μηχανής μαθημάτων.
- Σύνολο πρωτότυπων εικονογραφημένων μαθημάτων.
- Μετρήσιμη αξιολόγηση Computer Vision.
- Πολιτική απορρήτου για παιδιά και κάμερα.
- Έλεγχος διαθεσιμότητας εμπορικής ονομασίας Artora.

## Κανόνας διατήρησης γνώσης
Πριν από κάθε αλλαγή, ανάγνωση MASTER_PLAN, ARCHITECTURE, FEATURE_MATRIX, TEST_PLAN και παρόντος ledger. Μετά από κάθε αλλαγή, ενημέρωση του ledger με ημερομηνία, γεγονότα, αποτελέσματα tests και επόμενο βήμα. Καμία μη δοκιμασμένη δυνατότητα δεν σημειώνεται ως ολοκληρωμένη.
